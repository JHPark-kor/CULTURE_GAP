# CULTURE_GAP

[대시보드 열기](https://jhpark-kor.github.io/CULTURE_GAP/)

서울시 고령층 문화 이용 취약권역 지도입니다.

- 거리, 경사, 모바일 이용량 부족도, 취약노인 규모를 각각 25% 반영
- 상위 10% DBSCAN 취약권역 73개와 분석대상 격자 21,263개
- 권역·격자 전환, 검색, 문화시설 표시 및 점수 상세 정보

기존 sgis-project 및 Culture-Gap-Analysis 사이트와 독립된 배포 저장소입니다.
원자료·분석 노트북·인증 파일은 포함하지 않으며, index.html에 공개용 지도 데이터와 라이브러리를 포함합니다.
데이터 출처는 대시보드의 분석 안내, Leaflet·Lucide 라이선스는 HTML에 수록했습니다.
